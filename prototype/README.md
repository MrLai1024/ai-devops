# AI DevOps · HTML 原型

纯 HTML / CSS / JavaScript 原型，**无接口、无构建步骤、无外部依赖**，所有数据为静态演示数据。

## 打开方式

直接双击 `index.html` 即可。

如果浏览器限制本地文件，也可以在当前目录运行：

```bash
python -m http.server 8787
```

然后访问 `http://localhost:8787`。

## 信息架构

**顶部导航（可配置）**

工作台 ｜ 项目空间 ｜ 应用中心 ｜ 原始需求 ｜ 能力中心 ｜ 平台管理 ｜ ⚙ 配置入口

- 工作台、应用中心、原始需求为占位模块，只保留入口与空白页。
- 配置入口支持显隐与排序。

**项目空间侧栏**

项目总览、需求管理、Agent 任务、代码仓、知识库、流水线、批次发布、应用运行、可观测、团队管理。

**能力中心**

能力目录、MCP 测试、策略与审计。

**平台管理**

用户与角色、环境与配额、功能开关、审计日志、平台发布。

## 重点演示路径

1. **新建项目**：项目空间 → 项目总览右上角「新建项目」，或切换项目弹窗底部。填写名称与标识后自动创建首个迭代并切换过去。
2. **团队管理**：项目空间 → 团队管理 → 固定高度成员列表（5 条/页）/ 添加成员 / 行内调整角色 / 移除成员；查看角色权限说明与最近成员变更。
3. **需求管理**：项目空间 → 需求管理 → 列表左上角新建需求、铺满页面高度分页（10 条/页）；按编号、标题、状态、优先级、责任人、应用、发布、更新逐字段筛选；「发布」列为下拉框，可单选关联、迁移或解除发布关联，已关联时显示「发布名称 (年-月-日 时:分 ~ 年-月-日 时:分)」，单行展示、超出宽度省略号截断；状态为分析 / 设计 / 开发 / 测试 / 发布，支持延期；需求详情分「详情 / 关联项 / 历史记录」三个 Tab，详情左右分栏（保存修改在右上角），左侧编辑标题/描述并发表评论，右侧修改状态、责任人、关联发布、优先级、验收标准，关联项展示关联应用、关联任务与关联发布，历史记录以时间轴按操作者、时间与操作内容展示每次字段变更、状态流转、关联发布变更、自动任务与延期操作。
4. **任务看板**：需求管理 → 任务看板 → 按执行状态查看 Agent 任务（卡片展示对应责任人）→ 点击任务在任务看板内切换为执行详情（保留侧栏与 Tab）；在需求详情中变更状态会自动创建对应类型的 Agent 任务（分析 / 设计 / 开发 / 测试 / 发布），进入队列并关联需求责任人；查看流式思考、工具调用、工作区文件与 Diff，底部可聊天追问、中断任务、重新执行，并支持通过 / 要求修改。
5. **发布管理**：需求管理 → 发布管理 → 查看当前迭代的发布列表；新建发布，填写名称、开始/结束时间并选择未延期且未关联其他发布的需求；一个需求最多关联一个发布；状态按时间段自动显示未开始 / 进行中 / 已结束；点击查看关联需求。
6. **代码仓与知识库**：项目空间 → 代码仓 → 点击仓库进入详情，查看文件树、README、分支与最新提交；合并请求 → 点击 MR 进入详情，查看变更说明、关联需求、流水线结果与代码评审评论，可批准 MR；配置 → 修改仓库名称、描述、默认分支与可见性。知识库 → 查看文档列表、RAG 索引状态并重建索引。
7. **批次发布**：批次发布 → 审批通过 → 开始发布 → order-worker 失败、order-admin 被阻断 → 重试失败项 / 逐项回滚。
8. **能力配置**：能力中心 → 切换 REST / MCP 开关 → MCP 测试 → dry-run 响应。
9. **顶部配置**：⚙ 配置入口 → 隐藏/显示、上移/下移入口。
10. **全局搜索**：顶部搜索项目、需求、任务、能力。
11. **项目切换**：侧栏项目卡片 → 客户运营 / 智能客服。
12. **运行环境**：应用运行 → test / prod 切换。
13. **平台管理**：功能开关、审计日志、平台发布。

## 数据说明

静态数据集中在 `app.js` 顶部：

- 3 个初始项目、3 个迭代、20 条需求（可新建项目，自动生成首个迭代）
- 9 个初始 Agent 任务（含运行中执行流、文件树与聊天记录；需求状态变更时自动追加任务）
- 3 条当前迭代发布排期（进行中 / 未开始 / 已结束）
- 6 个应用（test / prod）
- 6 个代码仓（含分支、演示文件与 MR 评论）、4 篇知识库文档
- 6 条流水线、7 个能力、4 条告警
- 10 个用户、项目成员与角色（成员列表 5 条/页）、7 个功能开关、审计事件

所有交互只修改浏览器内存，刷新页面后恢复初始状态。

## 文件

- `index.html` — 页面壳与顶部导航
- `styles.css` — 浅色混合视觉系统（无黑色背景）
- `app.js` — 静态数据、hash 路由、页面渲染与交互
