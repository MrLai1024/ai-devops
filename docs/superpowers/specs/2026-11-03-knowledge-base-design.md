# 知识库与平台总库设计方案

> 版本：v0.1
> 日期：2026-11-03
> 状态：已确认（待实现）
> 范围：项目知识库列表、文档预览、Markdown 编辑、平台总库发布
> 关联：[AI DevOps 平台总体设计方案](2026-10-23-ai-devops-platform-design.md)

---

## 1. 背景与目标

### 1.1 背景

当前知识库页面是「文档列表 + 抽屉预览」，只展示少量文档元数据，正文以纯文本呈现，无法编辑，也没有跨项目共享能力。

需求开发过程中会产生需求规格（PRD）、方案设计、测试方案、运行手册等文档。知识库应承载当前项目的全部文档产物，默认仅供本项目检索；其中部分文档可以同步到平台总库，供其他项目检索。

### 1.2 目标

1. 知识库按项目沉淀需求规格、方案设计等开发过程文档。
2. 文档默认仅当前项目可见、可检索。
3. 支持将文档同步到平台总库，并支持取消发布。
4. 平台总库展示所有项目已发布的文档，跨项目只读。
5. 点击文档进入独立预览页，展示渲染后的 Markdown 正文与元信息。
6. 提供 Markdown 编辑态：分栏编辑与实时预览、格式化工具栏、保存与取消。
7. 支持新建文档，可选择一个关联需求，也可保持项目级文档。

### 1.3 非目标

- 不做真实 RAG、向量检索或 Embedding；只保留索引状态与检索范围展示。
- 不做文档删除、归档、版本历史与变更对比。
- 不做评论、协同编辑、附件、导入导出。
- 不做发布审批流；发布/取消发布即时生效。
- 不做 Agent 自动生成文档；本期只支持手动新建与编辑。
- 不做所见即所得富文本编辑器。
- 不新增顶部导航或侧栏入口；平台总库作为知识库页面的 Tab。

## 2. 信息架构与路由

知识库仍归属项目空间侧栏，保持「知识库」高亮。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/knowledge` | 知识库列表 | Tab：本项目文档 / 平台总库 |
| `#/knowledge/<docId>` | 项目文档预览 | 文档必须属于当前项目 |
| `#/knowledge/<docId>/edit` | 项目文档编辑 | 文档必须属于当前项目 |
| `#/knowledge/global/<docId>` | 平台总库文档预览 | 文档必须已发布；跨项目只读 |

- 直接访问 `#/knowledge/<docId>` 时，根据文档所属项目同步项目上下文。
- `#/knowledge/global/<docId>` 不切换当前项目上下文。
- 文档不存在、不属于当前项目或未发布时展示「未找到」，提供返回知识库入口。
- 从预览页返回知识库时回到对应 Tab；从总库预览返回总库 Tab。
- 顶部导航「项目空间」保持激活，侧栏「知识库」激活。

## 3. 数据模型

在现有 `DOCS` 上扩展：

| 字段 | 说明 |
| --- | --- |
| `id` | 文档编号，新建从 `doc-7` 起递增 |
| `projectId` | 所属项目 |
| `requirementId` | 可选关联需求；为空表示项目级文档 |
| `title` | 文档标题 |
| `type` | 需求规格 / 方案设计 / 测试方案 / 运行手册 / 其他 |
| `owner` | 负责人，新建时为当前用户张明 |
| `content` | Markdown 正文 |
| `status` | 已索引 / 索引中 |
| `createdAt` | 创建日期，格式 `YYYY-MM-DD` |
| `updated` | 更新展示值，保存时刷新 |
| `updatedBy` | 最近更新人 |
| `published` | 是否同步到平台总库 |
| `publishedAt` | 发布时间，可为空 |
| `publishedBy` | 发布人，可为空 |

规则：

- 新建文档默认 `published: false`、`status: 索引中`，保存后短暂模拟索引并回到「已索引」。
- 发布为同一文档同步可见，不复制副本；源项目编辑后总库同步展示最新内容。
- 取消发布只改变可见范围，不删除文档。
- 关联需求必须属于文档所属项目，可为空。
- 编辑保存后刷新 `updated`、`updatedBy`，状态置为「索引中」并写审计。

## 4. 知识库列表

### 4.1 页面头部

- 标题：知识库
- 副标题：`项目：<项目名> · 需求规格、方案设计与交付文档`
- 操作：重建索引、新建文档

### 4.2 本项目文档 Tab

筛选：

- 关键词：匹配标题与正文，忽略大小写
- 类型：全部 / 需求规格 / 方案设计 / 测试方案 / 运行手册 / 其他
- 关联需求：全部 / 未关联 / 当前项目具体需求

表格列：

| 列 | 内容 |
| --- | --- |
| 文档 | 标题 + 文档编号 |
| 类型 | 文档类型 |
| 关联需求 | 需求编号与标题；未关联显示「未关联」 |
| Owner | 负责人 |
| 检索范围 | 仅本项目 / 平台总库 |
| RAG 状态 | 已索引 / 索引中 |
| 更新 | 更新时间 |
| 操作 | 进入预览 |

- 点击整行进入 `#/knowledge/<docId>`。
- 空状态展示「当前项目还没有文档」，并提供新建入口。
- 「重建索引」保留在列表工具条，提交后提示已提交索引任务。

### 4.3 平台总库 Tab

筛选：

- 关键词：匹配标题与正文
- 类型：同项目文档
- 来源项目：全部 / 具体项目

表格列：

| 列 | 内容 |
| --- | --- |
| 文档 | 标题 + 文档编号 |
| 类型 | 文档类型 |
| 来源项目 | 文档所属项目 |
| Owner | 负责人 |
| 更新 | 更新时间 |
| 操作 | 进入只读预览 |

- 展示所有项目 `published: true` 的文档，包括当前项目已发布文档。
- 点击整行进入 `#/knowledge/global/<docId>`。
- 空状态展示「平台总库还没有公开文档」。

### 4.4 新建文档弹窗

字段：

1. 文档标题：必填，最大 80 字。
2. 文档类型：下拉选择，默认「需求规格」。
3. 关联需求：可选，选项来自当前项目需求；默认「不关联」。
4. 初始内容：可选，默认插入 `# <标题>`。

提交后：

- 生成文档编号，owner 为张明，创建时间取当前演示时间。
- 写入 `DOCS` 与审计。
- 关闭弹窗并进入 `#/knowledge/<docId>/edit`，直接开始编辑。

## 5. 文档预览页

采用左右布局：正文为主，右侧为元信息卡片。

### 5.1 头部

- 返回链接：← 返回知识库
- 类型标签、检索范围标签（仅本项目 / 平台总库）、RAG 状态
- 文档标题
- 文档编号、Owner、更新时间、来源项目（总库视图）

### 5.2 操作

- 文档属于当前项目：编辑、同步到平台总库 / 取消发布
- 文档属于其他项目（总库视图）：无编辑与发布操作，展示「只读」
- 当前项目已发布文档从总库进入时，仍可编辑；编辑跳转到项目编辑路由

### 5.3 正文

- 按 Markdown 渲染标题、段落、列表、引用、代码块、行内代码、粗体、斜体、删除线、链接、表格、分割线。
- 禁止原始 HTML 注入；链接仅允许 `http://`、`https://` 与站内相对链接。
- 正文区域限制阅读宽度，保持舒适行高。
- 内容为空时展示「暂无正文」。

### 5.4 右侧元信息

- 关联需求：编号 + 标题；同项目时可点击打开现有需求详情抽屉
- 文档类型
- 负责人
- 创建时间
- 更新时间
- 检索范围

### 5.5 发布

- 「同步到平台总库」：设置 `published: true`、发布人与时间，写审计，提示已同步。
- 「取消发布」：设置 `published: false`，写审计，提示已从平台总库移除。
- 发布/取消发布后刷新预览页与知识库列表；平台总库 Tab 同步变化。

## 6. 编辑页

### 6.1 顶部元信息

可编辑字段：

- 文档标题：必填，最大 80 字
- 文档类型
- 关联需求：不关联 / 当前项目需求

### 6.2 工具栏

提供以下 Markdown 常规操作：

- H1、H2
- 加粗、斜体、删除线
- 无序列表、有序列表
- 引用、行内代码、代码块
- 链接、表格、分割线
- 撤销、重做

工具栏按钮作用于当前选区；无选区时插入占位文本并选中占位部分，便于继续输入。

### 6.3 编辑布局

- 左侧 Markdown 源码文本域，右侧实时预览。
- 两栏独立滚动；窄屏下上下堆叠。
- 底部展示字数统计与保存状态。

### 6.4 保存与取消

保存：

- 校验标题非空、类型合法、关联需求属于当前项目。
- 更新文档标题、类型、关联需求、正文、更新时间与更新人。
- 状态置为「索引中」，写审计，返回预览页并提示已保存。
- 约 1.2 秒后模拟索引完成，状态回到「已索引」。

取消：

- 无修改时直接返回预览页。
- 有未保存修改时弹出确认，提供「继续编辑」与「放弃修改」。

### 6.5 编辑器历史

- 维护轻量编辑历史，支持工具栏撤销/重做。
- 文本域原生 Ctrl/Cmd+Z 仍可用。

## 7. 与现有功能的关系

- 移除原文档抽屉预览，`open-doc` 改为路由跳转。
- 「重建索引」操作保留，移动到知识库列表工具条。
- 需求详情、任务、代码仓、项目列表等页面不受影响。
- 侧栏「知识库」与顶部导航「项目空间」保持原有高亮逻辑。
- 平台总库只展示文档，不引入新的导航入口。

## 9. 页面状态

新增：

- `knowledgeTab`：`project` / `global`
- `knowledgeSearch`：关键词
- `knowledgeType`：`all` 或具体类型
- `knowledgeReq`：`all` / `none` / 需求编号
- `knowledgeSource`：`all` / 项目 ID
- `docSeq`：文档编号序列

交互：

- 切换 Tab 重置关键词、类型与对应筛选。
- 编辑页元信息与正文仅在点击保存后写回文档。
- 发布/取消发布、保存、新建文档均写审计。
- 编辑页离开前如有未保存修改需确认。

## 10. 测试与验收标准

1. 知识库页面提供「本项目文档 / 平台总库」两个 Tab。
2. 本项目 Tab 只展示当前项目文档，支持关键词、类型、关联需求筛选。
3. 平台总库 Tab 只展示已发布文档，支持关键词、类型、来源项目筛选。
4. 点击文档进入独立预览页，Markdown 标题、列表、代码等正确渲染。
5. 预览页展示类型、Owner、创建/更新时间、关联需求与检索范围。
6. 点击编辑进入分栏编辑页，工具栏可插入标题、加粗、列表、引用、代码、链接、表格。
7. 输入内容时右侧实时预览同步更新。
8. 保存后标题、类型、关联需求与正文更新，状态经历「索引中」并回到「已索引」。
9. 取消编辑不保存；有修改时出现确认。
10. 新建文档可选关联需求，创建后进入编辑页并出现在本项目列表。
11. 发布后文档出现在平台总库 Tab；取消发布后消失。
12. 跨项目总库文档只读，显示来源项目；直接访问未发布跨项目文档展示未找到。
13. 直接访问项目文档路由时项目上下文正确。
14. 无控制台报错，现有需求、任务、代码仓、项目列表功能不回归。
